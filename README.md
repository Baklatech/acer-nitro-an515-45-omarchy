# Acer Nitro AN515-45 под Omarchy: подсветка клавиатуры и клавиша N

Из коробки на этом ноутбуке под Omarchy нельзя менять цвет 4-зонной RGB-подсветки, а клавиша N (NitroSense) рядом с Num Lock ничего не делает. Этот репозиторий чинит оба пункта одной командой.

## Установка

```sh
git clone https://github.com/Gnome627/acer-nitro-an515-45-omarchy.git
cd acer-nitro-an515-45-omarchy
./install.sh
```

Запускать от обычного пользователя, пароль `sudo` скрипт спросит сам. Перезагрузка не нужна, повторный запуск безопасен. На другой модели скрипт остановится; обойти проверку можно через `./install.sh --force`.

## Что получится

- Клавиша N переключает подсветку по кругу, Shift + N — в обратную сторону:
  - ровные цвета: белый, красный, оранжевый, зелёный, бирюзовый, синий, фиолетовый, четыре цвета по зонам;
  - цвета текущей темы Omarchy: ровный цвет темы, палитра темы по четырём зонам, бегущая палитра, а также дыхание, зум и сдвиг цветом темы;
  - неон, радуга и «выключена».
- При смене темы Omarchy клавиатура перекрашивается сама, если выбран пресет с цветом темы.
- Выбранный вариант возвращается после перезагрузки.
- Менять подсветку можно без `sudo`.

Бегущую палитру прошивка не умеет, поэтому цвета по зонам двигает фоновый процесс — пользовательский юнит systemd `kbd-backlight-shift`. Он работает, только пока выбран этот пресет; скорость задаётся последним числом в строке пресета. Эффекты прошивки «метеор» и «мерцание» на AN515-45 не работают, поэтому их в списке нет.

Цвет темы берётся из её файла `keyboard.rgb`, а если его нет — из `accent` в `colors.toml`; палитра — это цвет темы и самые непохожие на него цвета из всего `colors.toml`, включая цвет текста. Если разных цветов в теме меньше четырёх, они повторяются; вместо `auto` в строке пресета можно задать имена вручную, например `red,yellow,green,blue`. От батареи бегущая палитра стоит на месте, чтобы не тратить заряд. Насыщенность поднимается, потому что приглушённые цвета тем на светодиодах выглядят почти белыми.

Пресеты лежат в начале `~/.local/bin/kbd-backlight`. Формат строк описан там же в комментарии: можно менять цвета, скорость эффектов и порядок.

```sh
kbd-backlight next      # следующий пресет
kbd-backlight prev      # предыдущий пресет
kbd-backlight list      # список, текущий отмечен звёздочкой
kbd-backlight restore   # применить последний выбранный
```

## Что ставится

| Что | Куда | Зачем |
|---|---|---|
| Пакет `acer-wmi-linuwu-dkms-git` из AUR | DKMS | Замена штатного `acer_wmi` с поддержкой 4-зонной подсветки |
| `acer-wmi-an515-45-patch` | `/usr/local/sbin/` | Включает для AN515-45 альтернативный протокол подсветки |
| `60-acer-wmi-an515-45.hook` | `/etc/pacman.d/hooks/` | Применяет патч заново при обновлении пакета, до пересборки DKMS |
| `99-acer-kbd-backlight.rules` | `/etc/udev/rules.d/` | Даёт группе `wheel` запись в файлы подсветки |
| `kbd-backlight` | `~/.local/bin/` | Переключение пресетов |
| `kbd-backlight-restore` | `~/.config/omarchy/hooks/post-boot.d/` | Возврат цвета после загрузки |
| `kbd-backlight-theme` | `~/.config/omarchy/hooks/theme-set.d/` | Перекраска при смене темы |
| Привязки `XF86Presentation` и `SHIFT + XF86Presentation` | `~/.config/hypr/bindings.lua` | Клавиша N и Shift + N |

## Почему нужен патч

Модуль [acer-wmi-linuwu](https://github.com/adityaruplaha/acer-wmi-linuwu) знает AN515-45, но использует для неё обычный протокол: эффекты вроде радуги работают, а статические цвета гасят клавиатуру. С альтернативным протоколом, который в модуле уже есть для AN515-55 и AN515-58, цвета работают. Патч добавляет одну строку `.four_zone_kbd_alt = true` в описание модели.

Если автор модуля сильно изменит исходник, патч не применится и напишет об этом предупреждение при обновлении пакета.

Клавиша N отдаёт обычный скан-код `f5`, который systemd уже превращает в `XF86Presentation`, поэтому для неё достаточно привязки в Hyprland.

## Удаление

```sh
./uninstall.sh           # убрать скрипты, привязку, хук и правило
./uninstall.sh --purge   # то же и удалить модуль, вернув штатный acer_wmi
```

## Проверено на

Nitro AN515-45, BIOS V1.08, ядро 7.2.5-omarchy, `acer-wmi-linuwu` 7.3.0.1.r68.
