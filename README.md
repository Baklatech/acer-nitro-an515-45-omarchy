# acer-nitro-an515-45-omarchy

На Acer Nitro AN515-45 под Omarchy включает цветную подсветку клавиатуры и оживляет клавишу N.

```bash
git clone https://github.com/Baklatech/acer-nitro-an515-45-omarchy && cd acer-nitro-an515-45-omarchy && ./install.sh
```

N переключает подсветку, Shift+N крутит её назад. Есть пресеты в цвет темы. [Подробно](docs/guide.md).
